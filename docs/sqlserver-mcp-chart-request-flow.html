从前端发起任务到 SqlServer MCP、制图与流式回复 — 请求链路图

基于本仓库典型部署：前端 @langchain/langgraph-sdk →（经 Nginx 时）/api/langgraph → LangGraph 图 lead_agent；MCP 来自 extensions_config.json 中 sqlserver-mcp；制图一般由沙箱 bash + Python（如 matplotlib）写 /mnt/user-data/outputs 后由模型总结并 present_files 等呈现。

1. 时序：发起一次对话与工具调用

sequenceDiagram
    autonumber
    participant U as 用户
    participant FE as 前端 useStream submit

    participant LG as LangGraph API
    participant AG as 图 lead_agent
    participant LLM as 大模型 API
    participant TN as 工具执行
    participant MCP as MCP sqlserver 子进程
    participant SQL as SQL Server
    participant SB as 沙箱 bash
    participant OUT as outputs 目录

    U->>FE: 输入任务并发送
    FE->>LG: thread.submit lead_agent
    opt 经统一入口
        FE->>NX: HTTPS /api/langgraph/*
        NX->>LG: 转发到 LangGraph 或 Gateway 内嵌运行时
    end
    LG->>AG: 创建 / 恢复 run，流式执行图
    AG->>LLM: 绑定工具列表后请求回复
    LLM-->>AG: assistant + tool_calls（如 execute_sql / bash）
    AG->>TN: 执行工具调用

    alt SqlServer MCP 工具
        TN->>MCP: stdio JSON-RPC（langchain-mcp-adapters）
        MCP->>SQL: 只读 SELECT（pyodbc / SQLAlchemy）
        SQL-->>MCP: 行集
        MCP-->>TN: ToolMessage 结果
    end

    alt 制图（典型路径）
        TN->>SB: bash：运行 python 生成图表文件
        SB->>OUT: 写入 PNG/SVG 等到 outputs
        SB-->>TN: 命令输出
    end

    TN-->>AG: 工具结果回注状态
    AG->>LLM: 多轮直到无 tool_calls 或结束
    LLM-->>AG: 最终自然语言 + 可选 present_files
    AG-->>LG: SSE / 分块流式事件
    LG-->>FE: messages / values / custom 等流
    FE-->>U: 渲染消息、附件与制品

说明与代码锚点

  • 前端提交：frontend/src/core/threads/hooks.ts 中 useStream（assistantId: "lead_agent"）与 thread.submit。
  • LangGraph 图注册：backend/langgraph.json → lead_agent → deerflow.agents:make_lead_agent。
  • MCP 工具装配：deerflow/tools/tools.py 中 get_available_tools + deerflow/mcp/cache.py + deerflow/mcp/tools.py 的 get_mcp_tools。
  • SqlServer MCP 服务定义：extensions_config.json 的 sqlserver-mcp；实现：mcp_servers/sqlserver_mcp_server.py（工具如 execute_sql）。
  • 制图：模型通过配置中的沙箱工具（如 bash）执行 Python 写图；网关模式下图与标准模式一致，仅 LangGraph 进程可能合并进 Gateway。
