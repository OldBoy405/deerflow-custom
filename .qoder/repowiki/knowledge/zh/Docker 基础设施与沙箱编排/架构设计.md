- **入口层**：`nginx` 作为统一反向代理（端口 2026），通过路径匹配将流量分发至 `frontend` (Next.js) 和 `gateway` (FastAPI)，并支持 SSE 流式传输。
- **应用层**：`frontend` 和 `gateway` 分别承载前端界面与后端逻辑，通过 `docker-compose.yaml` (生产) 或 `docker-compose-dev.yaml` (开发) 进行服务编排。
- **沙箱管理层**：`provisioner` 服务运行在 Docker 容器内，通过挂载的 `kubeconfig` 连接宿主机 Kubernetes 集群，动态创建/销毁 Pod 和 NodePort Service 以实现隔离的代码执行环境。
- **数据持久化**：利用 Docker Volumes 管理 PostgreSQL 数据、Python 虚拟环境 (.venv) 及 UV 缓存，确保开发环境重启后的依赖一致性。
