- **统一入口与路由**：根目录 `Makefile` 封装了开发（`make dev`）与生产（`make up`）的统一工作流；Nginx 作为反向代理（端口 2026），将流量分发至 Next.js 前端（3000）和 FastAPI 网关（8001）。
- **跨模块配置契约**：`config.yaml` 和 `extensions_config.json` 是全局状态中心，定义了模型、工具、技能路径及 MCP 服务器，被后端运行时、前端 API 客户端及 Docker 容器共同读取。
- **沙箱隔离边界**：通过 `sandbox` 配置项在本地执行、Docker 容器或 Kubernetes Provisioner 之间动态切换，确保代码执行的安全性与资源隔离。
- **技能与工具扩展机制**：`skills/` 目录与 `mcp_servers/` 遵循标准化的文件结构，由后端动态加载并注入到 Agent 的执行上下文中，支持热插拔式的能力扩展。
