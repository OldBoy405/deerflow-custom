- **分层架构**：模块分为 `public`（通用公共技能库）和 `custom`（定制化业务技能）两个顶层目录。
- **标准化契约**：每个技能子模块均遵循统一的目录结构，以 `SKILL.md` 为核心入口，包含 YAML 元数据（触发条件、兼容性）和 Markdown 执行工作流。
- **资源隔离模式**：采用“渐进式披露”设计，将重型依赖（如 `scripts/` 中的 Python/JS 脚本、`references/` 中的详细规范、`templates/` 中的提示词模板）与核心逻辑解耦，仅在需要时加载。
- **执行边界**：技能通过标准化的命令行接口（CLI）或 MCP 协议与外部环境交互，例如 `chart-visualization` 调用 Node.js 脚本生成图表 URL，`label-verification` 调用 Python 脚本下载并比对图片。
