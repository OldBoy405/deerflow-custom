- 核心业务逻辑与 API 调用封装在 `src/core` 目录下，按领域（如 `auth`, `threads`, `i18n`）划分模块并导出统一入口。
- 所有涉及用户交互的复杂 UI 组件均放置在 `src/components` 下，并进一步细分为 `ui`（基础）、`ai-elements`（AI 特有）和 `workspace`（业务场景）。
- 采用 "use client" 指令明确区分服务端组件与客户端组件，特别是在需要访问浏览器 API 或 React Hooks 的边界处。
- 国际化文案通过 `src/core/i18n` 模块管理，组件内使用 `useI18n` Hook 获取翻译函数，避免硬编码字符串。
