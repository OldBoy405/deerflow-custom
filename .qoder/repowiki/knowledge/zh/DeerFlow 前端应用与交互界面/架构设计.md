- **框架与路由**：采用 Next.js (App Router) 作为核心框架，利用 `src/app` 目录实现文件系统路由。通过 `(auth)` 路由组处理登录与初始化，`[lang]` 动态段支持国际化文档（集成 Nextra），`workspace` 路径承载核心业务逻辑。
- **状态与数据流**：使用 `@tanstack/react-query` 管理服务端状态，结合自定义 Hooks（位于 `src/core`）封装对 LangGraph SDK 及后端 API 的调用。`src/core/api` 模块统一处理 CSRF 令牌注入与静态演示模式的客户端适配。
- **组件架构**：遵循原子化设计，`src/components/ui` 存放基于 Radix UI 和 Tailwind CSS 的基础组件，`src/components/ai-elements` 和 `src/components/workspace` 封装业务级交互组件（如聊天流、代码块、画布）。
- **服务端边界**：在 `layout.tsx` 中通过 `getServerSideUser` 执行服务端鉴权守卫，确保受保护路由的安全性；通过 `next.config.js` 配置 API 重写规则，将 `/api/*` 请求代理至内部网关或 LangGraph 服务。
