- **分层架构**：`app/gateway` 为 FastAPI 入口层，负责路由分发、认证中间件及生命周期管理；`packages/harness/deerflow` 为核心引擎层，封装智能体工厂、中间件链及运行时组件。
- **智能体组装**：采用 `create_deerflow_agent` 工厂模式，通过 `RuntimeFeatures` 声明式组装中间件链（如沙箱、记忆、循环检测、安全终止等），支持动态上下文注入与工具错误隔离。
- **运行时核心**：内置 `RunManager` 管理并发执行状态，`ChannelManager` 桥接 IM 平台（钉钉、飞书等）与智能体线程，支持流式响应与文件附件处理。
- **持久化抽象**：通过 `checkpointer` 和 `store` 提供者模式支持内存、SQLite 及 PostgreSQL 后端，实现线程状态与元数据的解耦存储。
- **安全与隔离**：实施基于 JWT 的用户隔离机制，结合 `SandboxMiddleware` 提供文件系统沙箱，确保多租户环境下的数据安全性。
